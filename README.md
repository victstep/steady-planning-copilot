# Steady — AI Daily Planning Copilot

A responsive HTML, CSS, and JavaScript prototype for a human-controlled planning copilot.

## Run locally

Open `index.html` in a browser to view the product landing page. Select **Try the demo** to open `prototype.html`, the interactive task-planning prototype. No build tools or dependencies are required.

## Deployment

Push this static folder to GitHub, then enable GitHub Pages from the default branch and project root. The deployed `index.html` is the live landing page; `prototype.html` is the linked interactive demonstration.
